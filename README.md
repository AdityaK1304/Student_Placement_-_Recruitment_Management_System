
# Student Placement & Recruitment Management System

## Project Overview
A web-based student placement management
application developed using Python, Flask and MySQL.

## Technologies
- Python
- Flask
- MySQL
- Pandas
- HTML
- CSS

## Features
- Student CRUD Operations
- Company Management
- Placement Tracking
- Student Search
- SQL Joins
- Placement Analytics
- Web Dashboard

## Installation

pip install -r requirements.txt

## Run Project

python app.py

## Localhost

http://127.0.0.1:5000
